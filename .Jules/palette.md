## 2024-05-14 - Improve Cursor Interaction on Inventory Slot Button
**Learning:** `Button` instances built via scenes often define properties inside Godot GUI or individual scripts, resulting in inconsistent `mouse_default_cursor_shape`. Defining standard button behavior (e.g. `Control.CURSOR_POINTING_HAND`) in an inherited script's `_ready()` (like `InventorySlotButton`) ensures uniform UI experience across all dynamically instantiated components without polluting instantiation code in UI managers (`hud.gd`).
**Action:** When a custom button class (`InventorySlotButton`) is heavily dynamically instantiated throughout the application, embed UI micro-interactions (cursor shape, generic focus themes) directly in its `_ready()` to avoid redundancy and guarantee universal applicability.
