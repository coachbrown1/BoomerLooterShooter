## 2026-03-12 - Cache High-Frequency Group Lookups Safely using `is_instance_valid()`
**Learning:** Calling `get_tree().get_nodes_in_group()` or `get_tree().get_first_node_in_group()` in high-frequency functions like `_process` or `_physics_process` (or functions called by them) can cause significant performance overhead due to O(N) tree traversals per frame. Using boolean flags to cache references is unsafe in Godot since nodes can be freed, leaving the flag true but the reference invalid (causing "attempt to call function on a previously freed instance" crashes). It can also cause early caching of `null` if the target node hasn't entered the scene tree yet.
**Action:** Lazily cache the result of these group lookups the first time they are executed using a local member variable, and check the validity using `is_instance_valid(cached_node)`. This guarantees safety and correctly re-fetches the node if it is freed or initialized late, all while converting O(N) traversals into O(1) lookups.
