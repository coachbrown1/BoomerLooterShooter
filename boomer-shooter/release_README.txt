BoomerShooter
Version: {{VERSION}}

What to send:
- Send the whole folder contents together, or send the included zip.
- Your friend should extract the zip before launching the game.

How to play:
- Run BoomerShooter.exe.
- Single Player starts immediately.
- Host starts a co-op lobby on the chosen port.
- Join connects to a host IP and port.

Co-op notes:
- The host should click Host, then Start Game after the client joins.
- On the same local network, use the host machine's LAN IPv4 address.
- Across the internet, the host must port-forward the chosen port to their PC.
- Default port: 7000

Controls:
- Move: WASD
- Jump: Space
- Sprint: Shift
- Shoot: Left Mouse
- Interact: E
- Reload: R
- Inventory: Tab
- Mouse capture / release: Esc
- Fullscreen toggle: F11 or Alt+Enter

Known limitations:
- This build is a friend-playable prototype, not a store release.
- Co-op currently assumes one host and one client.
